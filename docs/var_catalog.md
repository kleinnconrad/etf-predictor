## Dynamic Feature Engineering Suffixes

The base variables listed above do not just yield simple returns (`1M_ret`). The pipeline dynamically applies advanced quantitative transformations, appending specific suffixes to the variable names. This allows the model to process 2nd derivatives, mean reversions, and regime shifts.

| Suffix | Transformation | Description | Applied To |
| :--- | :--- | :--- | :--- |
| `_Level` | Absolute Price/Rate Level | The raw value is preserved to allow the model to recognize absolute thresholds (e.g., a negative yield curve, or VIX > 30). | Interest Rates, Spreads, Sentiment |
| `_63D_ret`, `_126D_ret`, `_252D_ret` | Multi-Timeframe Momentum | Percentage change over 3 months, 6 months, and 1 year (`pct_change`). Measures the velocity of the trend. | Equities, Commodities, Absolute Levels |
| `_63D_diff`, `_126D_diff`, `_252D_diff` | Absolute Point Momentum | The absolute point difference over 3, 6, and 12 months. Used instead of percentages for stationary data like interest rates. | Interest Rates, Spreads, Unemployment |
| `_Dist_SMA200` | Distance to Trend (Mean Reversion) | The percentage distance of the current value from its 200-day Simple Moving Average. Indicates if an asset is overextended or oversold relative to its long-term baseline. | All Variables |
| `_YoY_Accel_3M` | Macro Acceleration (2nd Derivative) | Measures the 1-year rate of change *today*, minus the 1-year rate of change *3 months ago*. This determines if a macro trend (like inflation or money supply) is accelerating or decelerating. | Macro Indicators, Employment, Money Supply |
| `_Roll_ZScore_2Y` | Regime Normalization | The current value expressed as a standard deviation (Z-Score) relative to a rolling 2-year lookback window. Neutralizes structural drift and highlights abnormal stress in the *current* market regime. | VIX, Credit Spreads, Unemployment |
